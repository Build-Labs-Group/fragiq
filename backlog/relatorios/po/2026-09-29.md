## Como este backlog chegou aqui (importante)

Esta sessão da rotina não tinha credencial do GitHub para os repositórios
(`git clone` pediu usuário; o proxy recusou o push porque o repositório não
está nas fontes autorizadas da sessão). Por isso:

- a varredura usou a `main` da cópia local do Murilo (clonada para uma pasta
  temporária, sem tocar a árvore de trabalho), no último `origin/main` que essa
  cópia tinha buscado;
- a pasta `backlog/` foi escrita direto na pasta local do repositório, **sem
  commit e sem push**. Para a rotina dos devs enxergar, é preciso commitar só
  `backlog/` e dar push (`git add backlog && git commit -m "backlog(po): varredura 2026-09-29" && git push`).

Suposição: é melhor deixar os arquivos prontos na pasta local do que perder a
rodada.
